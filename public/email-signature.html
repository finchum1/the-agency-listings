Email signature

Copy the signature below into your email app. Use Copy signature for Gmail, Apple Mail and most apps, or Copy HTML code for any provider that has an HTML signature box.

HTML code

For email providers with an HTML signature field. This is the exact same signature — everything it needs is inside the code, and the images load from terrencefinchum.com.

Gmail

  1. Settings (gear) → See all settings → General → scroll to Signature → Create new.
  2. Click Copy signature above, click in the box and paste (Cmd/Ctrl + V). Gmail has no HTML box, so paste the signature itself, not the code. Choose it under Signature defaults, then Save changes at the bottom.

Outlook (new Outlook / Outlook on the web)

  1. Settings (gear) → Accounts → Signatures → New signature.
  2. Paste the signature (from Copy signature), set it as your default for new messages and replies, and Save.

Apple Mail

  1. Mail → Settings → Signatures → +, then untick "Always match my default message font".
  2. Paste the signature. If the picture shows as a blank box, send yourself a test first — Apple Mail sometimes needs a moment to fetch it.

Providers with an HTML box

  1. Open the signature settings and look for an HTML, Source or </> option (Zoho, Microsoft 365 admin, GoDaddy/Titan, Namecheap and many others have one).
  2. Click Copy HTML code above and paste it into that box.
