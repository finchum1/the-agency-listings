Gmail

  1. Settings (gear) → See all settings → General → scroll to Signature → Create new.
  2. Click in the box and paste (Cmd/Ctrl + V). Choose it under Signature defaults, then Save changes at the bottom.

Outlook (new Outlook / Outlook on the web)

  1. Settings (gear) → Accounts → Signatures → New signature.
  2. Paste, set it as your default for new messages and replies, and Save.

Apple Mail

  1. Mail → Settings → Signatures → +, then untick "Always match my default message font".
  2. Paste. If the picture shows as a blank box, send yourself a test first — Apple Mail sometimes needs a moment to fetch it.
